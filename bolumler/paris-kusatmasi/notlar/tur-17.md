# Tur 17 — harita turu onayı (2026-11-14)

Kapsam: HARITA ekleri KE-PK-H1…H5 (paris-çevre görünümü, Prusya halkası + telgraf teli kopması + kalabalık dolumu, balon izi/geri ok/yazı yığını/güvercin çizgileri, Tours ikonu/Prusya bölgesi/yatık sepet/gizli segment, kuş çizgileri + şerit yağmuru) — P02, P03b, P04a, P06a, P08, P11a. Aynı motion turuna: T eleştirisinin şartları M1 (P10 memur-3 okunurluk), M2 (P06b biniş IK), Y1 (yönetmen: memur-3 x ≈800, P10 f84/f200 lint), kurgucu notları (#21 temas, P10 f120 −18 dB, P01 kanat f9). Sıra: mekân sorumlusu (harita gravür dili şartnamesi) → yönetmen → motion → eleştirmen.

Orkestra kararı (küçük karar, kullanıcıya sorulmaz): mekanlar.md §5H'deki tasarımcı onayı bekleyen 5 madde (halka işareti teğet çubuk, Prusya bölgesi düz #8a93a0, ikon ölçüleri kuş 44 px / şerit 30×15, gizli segment nokta rengi, yeni renkler) mekân sorumlusunun önerisiyle KABUL; tasarim.md'ye sonra işlenir. Kit iğnesi mürekkep siyahı, şehir adları yazı katmanına, tarama ≥1 px.
