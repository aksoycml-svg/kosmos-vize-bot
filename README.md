# Instagram Hikâye Kanalı — Remotion Stüdyosu

Yaşanmış, az bilinen hikâyeleri kodla (Remotion + three.js) anlatan dikey video hattı.

- `bolumler/<slug>/` — araştırma, senaryo, sahne planı
- `src/` — bileşenler, 3B sahneler, kompozisyonlar
- `.claude/agents/` — ekip rolleri (araştırmacı, senarist, yönetmen, görüntü yönetmeni, tasarımcı, motion, eleştirmen)
- `.claude/skills/` — Remotion + hikâye/kanca skill'leri

Çalıştırma: `npm install` → `npm run dev` (Studio) · Render: `npx remotion render <Kompozisyon>`
